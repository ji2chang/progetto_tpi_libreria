# Progetto tpi libreria
## Requisiti
* Funzionali:
  - caricamento dati;
  - aggiunta libro;
  - eliminazione libro;
  - cancellazione intera libreria;
  - filtro di ricerca
* Non funzionali:
  - interfaccia bella e user friendly;
  - velocità delle response;
  - architettura Client-Server;
  - manutenibilità del codice;
  - sicurezza dei dati;
## USER STORY
1. Come utente della libreria digitale voglio visualizzare l’elenco completo dei libri disponibili in modo da poter consultare rapidamente le informazioni presenti nel catalogo.
2. Come amministratore della libreria voglio inserire un nuovo libro in modo da ampliare il catalogo con nuovi titoli.
